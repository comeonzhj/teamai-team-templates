# 决策记录（Decision Log）

> 会约束后续工作的选择都要留痕。**旧记录不改写**：要推翻就新增一条并注明「取代 D-xxx」。
> 新增条目复制底部模板，编号递增。状态：`提议 / 已通过 / 已取代 / 已废弃`。

## 模板

```markdown
## D-NNN｜一句话决策标题
- 日期：YYYY-MM-DD
- 状态：已通过
- 决策人：@who（参与：@a @b）
- 背景：为什么现在要定这件事（一段话）
- 备选方案：A…（选了）/ B…（放弃，为什么）
- 影响：对范围、排期、架构、后续工作的约束
- 取代：无 / D-xxx
```
