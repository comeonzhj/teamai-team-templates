# 术语与口径表（Glossary）

> 全队统一口径：数字、角色、状态的定义冲突时以本表为准。新增术语随时补，删除需在 `decisions.md` 留痕。

| 术语 | 定义 / 口径 | 备注 |
|---|---|---|
| 需求卡片 | 单条需求的最小承载单位（`templates/requirement-card.md`） | 一条卡片 = 一次可独立交付的范围 |
| AC（验收标准） | 可验证的完成判据，Given/When/Then 或可测陈述 | 不可测的 AC 一律退回 |
| DoD（完成定义） | 产出物 + 评审通过 + 状态更新 + 归档（协作公约第 10 条） | 与 AC 区分：AC 针对功能，DoD 针对工作项 |
| 交接包 | 阶段间的标准交付物集合（见 `stage-handoff` skill） | 缺项视为未交接 |
| 冒烟测试 | 核心链路正向用例的最小集合 | 发布前必须全绿 |
| P0/P1/P2/P3 | 缺陷分级：阻塞发布 / 严重 / 一般 / 轻微 | 依据：影响面 × 频率 × 有无绕行 |
| 灰度 | 按比例逐步放量（如 5% → 20% → 100%） | 每档观察 ≥ 30 分钟 |
| 处理时长 | 下单到发货确认的中位数（分钟） | 与平均数区分，防止长尾失真 |
| 月活商家 | 近 30 天 ≥ 1 次核心操作的商家数 | 核心操作 = 下单/发货/售后任一 |
| 【按需补充】 | | |
