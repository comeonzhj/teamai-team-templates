# AI 使用与保密红线

## 红线（任何 Agent 与成员都不得违反）

1. **凭据零落地**：token、密码、私钥不进代码、文档、提示词、提交信息。声明在 `env/secrets.yaml`，成员用 `teamai env set KEY` 设置，命令用 `teamai env exec -- <command>` 跑。
2. **隐私数据脱敏**：手机号、身份证、邮箱、真实用户姓名在采集当场脱敏后才允许写入任何文档（`guard-pii` hook 会提示）。
3. **未公开信息不外发**：未发布的产品计划、财务数字、用户数据不得发给外部服务；给 AI 工具的上下文按「最小必要」裁剪。

## Agent 工作规范

4. 先读上下文（`docs/context/current-status.md`），再动手；不要向用户重复索要已经写在文档里的背景。
5. 事实必须可溯源：引用数据写明口径和来源链接；无法溯源的数字标注「待核实」。
6. 生成内容（文案、代码、方案）要标注 AI 参与；对外物料按公司政策做 AI 生成声明。
7. 产出物落盘到团队模板规定的位置；不要在业务仓库里留下临时文件，不要把团队交付产物写进业务仓库的 git。
8. 不确定归属时问一句再做，比做完再返工便宜。

## 允许且鼓励

- 用 Agent 做初稿、评审预检、清单核对、回归用例生成。
- 用 `teamai contribute` 把踩过的坑沉淀成团队经验；用 `teamai recall <关键词>` 先搜团队是否已经遇到过。
