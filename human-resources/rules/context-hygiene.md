# 上下文维护规则（强制，Agent 必读）

## 什么时候更新 `docs/context/current-status.md`

- 候选人阶段变化（投递 → 筛选 → 面试 → Offer → 入职）或岗位状态变化（开放/暂停/关闭）
- 绩效周期节点（目标设定/自评/校准/反馈）推进
- 培养计划（IDP/培训/继任）状态变化
- 出现阻塞（HC 冻结、面试官档期、背调卡点）或解除

## 什么时候更新 `docs/context/decisions.md`

- 标准口径变更（评分锚点、职级要求、指标定义）、流程变更（面试轮次、审批链）
- 招聘需求的批准/驳回/冻结结论
- 推翻旧决策：新增一条并标注「取代 D-xxx」，不改写历史

## 书写格式

- 状态短句 + 日期 + 负责人；漏斗数字带口径与来源（如「到面率 32%，口径：近 90 天 SDE 岗，来源：ATS_URL」）。
- **绝不写入**：明文 PII、薪酬数字、绩效结果姓名对应表（见 `rules/pii-protection.md`）。
- 用聚合与代号：`候选人 A（C-0142）`、`P7 岗`、`绩效分布：S/A/B/C = 5/20/65/10`。

## 边界

- 个体敏感信息留在 ATS/HRIS；docs/ 只放流程、标准、聚合状态。
- 拿不准写不写：先脱敏，再问 hr-lead。
