# 隐私与个人信息保护红线（强制，不可删除）

HR 处理全公司密度最高的个人信息。违反本规则即事故。`guard-pii` hook 会提示，但**合规是人的责任**。

## 1. 最小必要与脱敏

1. 收集即脱敏：身份证号、手机号、银行卡号、家庭住址、健康信息在任何**共享**文档中必须掩码
   （如 `110***********1234`、`138****1234`）。原始数据只存在于 ATS/HRIS。
2. 薪酬、绩效结果、晋升结论属机密：按「需知」原则传播，不进共享文档、不进群聊、不进 AI 提示词。
3. 向 AI 提供候选人/员工信息时，只给评估所必需的字段；优先让 Agent 通过
   `teamai env exec --` 读取 ATS/HRIS，而不是把 PII 粘进对话。

## 2. 留存与删除

4. 候选人数据留存不超过 `DATA_RETENTION_DAYS`（默认 180 天，改前先核对当地法律）；到期删除或匿名化。
5. 候选人行使查阅/更正/删除请求时，48 小时内响应并走 ATS/HRIS 的正式流程。
6. 面试评价、背调报告按公司期限留存，离职员工数据按规定归档后删除。

## 3. 授权与告知

7. 背景调查必须有候选人**书面授权**后才能发起；范围不得超出岗位必要。
8. 收集新类别的个人信息前，先更新告知与授权文本（法务确认）。

## 4. 传播边界

9. 简历、面试评价、绩效记录不转发到非授权系统（个人网盘、外部聊天工具、未批准的模型）。
10. 任何疑似泄露（误发、误贴、误授权）立即上报 hr-lead + 法务，不自行补救后沉默。

## 5. Agent 附加约束

11. Agent 不得要求用户粘贴 PII；不得把 PII 写入 docs/ 或业务仓库；输出示例一律用虚构数据
    （张三/138****1234/【示例】）。
12. 生成的面试题、评价、JD 必须经人复核后才能使用（自动化不得直接做出录用/淘汰决定）。
