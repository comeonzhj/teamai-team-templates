# HRBP 岗位工作规范

适用：`rules/hrbp/`，仅 HRBP 岗位的 Agent 收到。

## 绩效管理

1. 绩效周期四节点管理：目标设定 → 期中回顾 → 评定与校准 → 反馈面谈；每节点有明确产出与截止日。
2. 目标设定用 SMART/OKR 口径：可衡量、有期初基线、有验收方式；期中改目标必须双方确认留痕。
3. 评定必须**先证据后结论**：以期初目标与 `competency-model.md` 为标准，逐条举证（SBI：情境-行为-影响）。
4. 校准会必开：跨团队对齐尺度，输出分布结论与个案调整理由；校准记录留档可复核。
5. 反馈面谈按 SBI 结构；负面反馈给改进计划与支持资源，不搞突然袭击（期中无预警 = 管理失职）。

## 员工关系

6. 申诉与冲突：24 小时内响应，过程保密、书面记录、结论书面告知；涉及合规的立即拉法务。
7. 离职面谈全覆盖，结论进聚合分析（脱敏），每月输出离职原因 TOP3 与管理建议。

## 业务支持

8. 每月与业务负责人对齐：组织健康度（流失率、敬业度、人才结构）、HC 节奏、关键岗位风险。
9. 人才决策（晋升/调岗/淘汰）以 `competency-model.md` 为唯一依据，负面决定必须有书面依据可复核。
