# HR 流程交接包（handoff）

## 标准结构

```text
<handoff-包>/
  00-summary.md        # 一页：岗位/事项目标、标准、当前状态、风险、需要谁决策
  01-<上游产出>        # 需求单 / JD / 筛选名单 / 面试结论 / 评定材料
  02-open-questions.md # 未决问题 + 建议 + 需要谁拍板 + 期限
  03-checklist.md      # 下游开工自检清单
```

## 各环节交接要点

- **HRBP/业务 → 招聘**：招聘需求单（HC、目标、到岗时间、薪酬带宽、面试官）+ intake 纪要
  （成功画像、必备项 ≤ 3、加分项、淘汰线）。
- **招聘 → 面试官**：JD + 简历（脱敏版）+ 筛选评分卡 + 本轮结构化题本与评分锚点。
- **面试官 → 招聘**：评分卡（每维度带行为证据）+ 结论（强烈推荐/推荐/保留/不推荐）+ 风险点。
- **招聘 → HR Ops**：Offer 审批链 + 背调授权与结论 + 入职信息（走 ATS，不走文档）。
- **HRBP → TD**：绩效与发展结论（九宫格定位、发展建议）→ IDP。

## 发出前自检

1. **无明文 PII**（身份证/手机/银行卡/薪酬）：全部掩码或改为 ATS 链接（`pii-protection.md`）。
2. 评估材料含标准 + 证据，可被第三人复核（`fairness-compliance.md`）。
3. 未决问题有 owner 与期限。
4. `current-status.md` 状态已流转（用代号，如候选人 C-0142）。

## 收到交接包时

跑 `03-checklist.md` 核对，缺项一次性列清单打回；核对通过后在 `current-status.md` 认领下一环节。
