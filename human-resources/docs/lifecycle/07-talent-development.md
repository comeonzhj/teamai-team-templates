# 环节 7 · 人才培养与继任（Talent Development）

> 主责：td ｜ 输入：绩效与发展结论、人才盘点

## 目标

把「差距」变成「有导师、有任务、有检查点的成长行动」，并保证关键岗位有继任。

## 进入条件

- 能力差距有依据（绩效结论、九宫格盘点、360 反馈）。

## 关键动作

1. **人才盘点**（半年）：九宫格（绩效 × 潜力），基于证据、会上校准、会下保密。
2. **IDP 制定**（`../templates/idp.md`）：发展目标 ≤ 2 个；行动按 70-20-10 拆
   （在岗实践 → 反馈 → 课程）；每个行动有导师/支持人 + 季度检查点 + 成功判据（行为改变）。
3. **培训**：需求从能力差距来；效果按柯氏四级评估（至少到「行为」层），结果进复盘。
4. **继任**：关键岗位 ≥ 1 ready-now + 1 ready-later；继任差距转 IDP 行动。
5. **保留**：高潜保留风险季度评估（流失风险 × 影响度）；优先发展机会与可见度，
   薪酬动作走带宽与审批。
6. **闭环**：季度检查点回顾 IDP 进展；半年复盘培养效果（数据脱敏进 `current-status.md`）。

## 产出物

- 盘点结论（九宫格，脱敏）、IDP（一人一策）、继任地图、培养效果复盘

## DoD

- [ ] 盘点结论有证据并经校准
- [ ] IDP 目标 ≤ 2 个、行动可执行、有导师与检查点
- [ ] 关键岗位继任缺口已转行动
- [ ] 敏感结论按需知范围传播（`rules/pii-protection.md`）

## 交接

## 常见坑

- IDP 写成课程清单，没有在岗实践。
- 盘点结果泄露（信任崩塌）。
- 培养只投高潜，骨干层断档。
