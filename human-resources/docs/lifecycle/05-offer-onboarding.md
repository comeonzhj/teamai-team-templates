# 环节 5 · Offer 与入职（Offer & Onboarding）

> 主责：recruiter（Offer）+ hr-ops（入职）｜ 产出 → 环节 6/7

## 目标

把「想来」变成「按时到岗并顺利活过前 90 天」。

## 进入条件

- 面试结论为推荐及以上；薪酬带宽内；背调书面授权已取得（如需）。

## 关键动作

1. **Offer 三核**：薪酬带宽合规、背调结论无红灯、审批链齐备（用人经理 + hr-lead + 财务如需）。
2. **Offer 沟通**：口头沟通（期望管理：职责、汇报、薪酬结构、到岗时间）→ 书面 Offer；
   沟通留痕；候选人异议 24h 内给答复路径。
3. **背调**：仅在书面授权后发起，范围限于岗位相关（学历/任职/离职原因/竞业）；
   疑点按事实核对，不扩大调查（`rules/pii-protection.md`）。
4. **入职准备**（hr-ops，`skills/hr-ops/hr-operations`）：入职清单（合同、账号、设备、导师、培训）；
   入职前 3 天发欢迎包；关键岗位拉通用人经理。
5. **入职 90 天**：30/60/90 天检查点（目标清晰度、融入、绩效信号），问题早发现早处理。

## 产出物

- Offer 记录（审批链 + 沟通留痕）+ 入职清单 + 90 天检查点安排

## DoD

- [ ] 三核通过，审批链完整
- [ ] 书面 Offer 与入职信息准确（数据走 ATS/HRIS，不走文档）
- [ ] 入职清单 100% 完成（当天）
- [ ] 90 天检查点已排期

## 交接

→ hr-ops：入职清单与权限开通
→ 绩效（环节 6）：新员工目标设定在入职 2 周内完成

## 常见坑

- 背调没授权先调查（合规事故）。
- Offer 薪酬超带宽没特批，入职后内部失衡。
- 入职第一天没人接、没账号——第一印象无法挽回。
