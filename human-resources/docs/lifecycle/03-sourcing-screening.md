# 环节 3 · 渠道与简历筛选（Sourcing & Screening）

> 主责：recruiter ｜ 产出 → 环节 4 面试

## 目标

用对的渠道找到对的人，并以**统一评分卡**公平、可复核地筛出面试人选。

## 进入条件

- JD 终版已上架；成功画像与淘汰线明确。

## 关键动作

1. **渠道策略**：内推（最高质量，48 小时内反馈）> 精准渠道（社区/猎头/垂直平台）> 海投；
   每渠道写预期量与质量，周度复盘转化。
2. **主动搜寻（sourcing）**：搜索词 × 目标公司 × 角色画像；触达话术个性化（提具体匹配点）。
3. **简历评分**（`../templates/screening-rubric.md`）：
   - 维度（学历/经验匹配、项目规模、技能证据、稳定性/连续性）各 1-5 分 + 写证据
   - **先定淘汰线再筛**；不凭「感觉」淘汰
   - 条件相当可盲审（隐去姓名/性别/年龄/照片）
4. **可疑项处理**：造假疑点记录证据，交背调核实，不在文档里下定论。
5. **隐私**：简历不外发、不进共享文档；ATS 链接 + 代号引用（`rules/pii-protection.md`）。

## 产出物

- 筛选评分卡（每人一份）+ 进入面试名单（代号）+ 渠道转化数据

## DoD

- [ ] 每位进入面试的候选人都有评分卡与证据
- [ ] 被淘汰者有理由（可复核）
- [ ] 无明文 PII 落在文档
- [ ] 漏斗数据已更新（口径见 `glossary.md`）

## 交接

→ 面试（环节 4）：评分卡 + JD + 本轮题本与评分锚点（结构化）

## 常见坑

- 「第一感觉不好」式淘汰（不可复核 = 不合规）。
- 渠道只靠海投，质量差还怪市场。
- 简历转发到群里讨论（隐私事故）。
