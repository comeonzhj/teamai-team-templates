# 环节 4 · 面试与评估（Interview）

> 主责：recruiter（组织）+ 面试官（评估）｜ 产出 → 环节 5 Offer

## 目标

用**结构化面试**收集行为证据，做出公平、可复核、可比较的评估。

## 进入条件

- 候选人有筛选评分卡；本轮题本与评分锚点已发给所有面试官。

## 关键动作

1. **面试前**：面试官过一遍维度、权重与锚点（同岗同标准）；分工不重叠（每人主打 2-3 维度）。
2. **面试中**：
   - STAR 追问（情境/任务/行动/结果），问过去的真实行为，不问观点感受
   - **提问禁区**（`rules/fairness-compliance.md`）：婚育、民族、宗教、政治、健康等
   - 预留候选人提问时间（体验 = 雇主品牌）
3. **面试后 24h 内**：填评分卡（`../templates/interview-scorecard.md`）——
   每维度给分 + **行为证据**（原话/数据），再给结论（强烈推荐/推荐/保留/不推荐）。
4. **汇总**：招聘汇总各轮，标注维度缺口（谁没覆盖到）；有争议进入加面而不是投票。
5. **候选人沟通**：每轮 48 小时内给进展；拒绝给体面、具体反馈。

## 产出物

- 各轮评分卡（证据完整）+ 面试结论 + 风险点

## DoD

- [ ] 同岗所有候选人使用同一套维度与锚点
- [ ] 每条评分有行为证据（「感觉不错」无效）
- [ ] 评价 24h 内回收
- [ ] 结论可被第三人复核

## 交接

→ Offer（环节 5）：评分卡汇总 + 结论 + 风险点（含背调关注点）

## 常见坑

- 引导性提问（「你应该用过 X 吧」）。
- 面试官各自出题，横向不可比。
- 面试结束不写证据，一周后凭记忆补评价。
