# 招聘原则与用人标准（Hiring Principles）

> 招聘与评估的共同基准（负责人：hr-lead）。修订走 `decisions.md` 留痕。

## 1. 用人原则

1. **为岗位招人，不为「感觉」招人**：先有成功画像，再看候选人。
2. **证据优先**：每个评估结论都指向可观察的行为/产出证据（STAR）。
3. **宁缺毋滥，但不追求完美画像**：必备项 ≤ 3 条，加分项不作淘汰依据。
4. **候选人体验即雇主品牌**：每轮 48 小时内给进展，拒绝给体面、具体反馈。
5. **合规底线**：见 `rules/fairness-compliance.md`（提问禁区、评估公平）。

## 2. 成功画像（Success Profile）模板

| 维度 | 问题 | 示例答案（面试验证点） |
|---|---|---|
| 12 个月后做得好 | 交付了什么、改变了什么 | 「独立负责 X，指标从 A 到 B」 |
| 必备能力（≤ 3） | 过往是否有同类规模的实践 | 行为事例 + 数据 |
| 加分项 | 有更好，没有不影响 | |
| 淘汰线 | 出现即不通过 | 如：无相关项目实操、诚信问题 |

## 3. 评估标准的使用

- 同一岗位：同一套维度、同一权重、同一评分锚点（`docs/templates/interview-scorecard.md`）。
- 评分锚点示例（1-5）：1 = 无相关经验；3 = 独立完成过同类任务；5 = 主导过更大规模并有可验证结果。
- 评语必须写行为证据；写不出证据的维度不得给分。

## 4. 岗位要求写法

- 必备项写「做过什么、达到什么程度」（可验证），不写「精通 X」。
- 禁止：年龄/性别/婚育/户籍/民族/宗教相关限制与暗示（合规红线）。
- 薪酬范围：能给就写（显著提升投递率与信任）。
