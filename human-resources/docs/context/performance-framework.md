# 绩效框架（Performance Framework）

> 绩效评定的口径与流程（负责人：hrbp）。修订走 `decisions.md` 留痕并全员告知。

## 1. 周期与节点

| 节点 | 时间 | 产出 | 责任人 |
|---|---|---|---|
| 目标设定 | 季初（第 1-2 周） | 目标卡（含权重与评分标准） | 员工 + 经理 |
| 期中回顾 | 季中 | 回顾记录（SBI 证据） | 经理 |
| 评定与校准 | 季末 + 1 周 | 评定表 + 校准结论 | 经理 + hrbp |
| 反馈面谈 | 校准后 1 周 | 面谈记录 + 行动计划 | 经理 |

## 2. 目标与权重

- 目标用 SMART/OKR：可衡量、有期初基线、有验收方式；权重合计 100%（业绩 70-80% + 能力/价值观 20-30%，可按岗位调）。
- 评分标准**期初写死**（如：指标 A 40% —— 达成 ≥100% = 5 分、90-99% = 4 分…），避免期末争议。
- 期中改目标必须双方确认留痕。

## 3. 评定等级（口径）

| 等级 | 定义 | 参考分布 | 后续动作 |
|---|---|---|---|
| S 卓著 | 超额且有标杆意义 | 0-10% | 激励 + 发展加速 |
| A 优秀 | 全面达成并有突出项 | 15-25% | 激励 + IDP |
| B 良好 | 达成预期 | 大多数 | 正常发展 |
| C 待改进 | 有明显差距 | 视情况 | 改进计划（PIP） |

> 分布是参考不是指标：不搞强制排序；偏离分布必须在校准会说明理由。

## 4. 校准会（Calibration）

- 输入：每人目标卡 + 证据 + 初评；输出：等级结论 + 调整理由（留档可复核）。
- 流程：经理陈述证据 → 交叉质询（「证据是什么」）→ 对齐尺度 → 定案。
- 偏差自检：近因/光环/趋中/宽严/相似性偏见（见 `rules/fairness-compliance.md`）。

## 5. 申诉

对结论有异议 → @hr-lead；24 小时内响应，按「标准 + 证据」复核，结论书面告知（保密）。
