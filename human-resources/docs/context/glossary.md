# 指标口径与术语表（Glossary）

> 数字口径的唯一定义处；汇报与复盘以本表为准。口径变更走 `decisions.md`。

## 招聘指标

| 指标 | 口径 | 备注 |
|---|---|---|
| 筛选通过率 | 进入面试人数 ÷ 有效投递数 | 有效投递 = 满足必备项 |
| 到面率 | 实际面试人数 ÷ 约面人数 | 低于 60% 查约面话术/档期 |
| 面试通过率 | 通过人数 ÷ 完成面试人数 | 分轮次统计 |
| Offer 接受率 | 接受数 ÷ 发出数 | 拒因分类记录 |
| 平均招聘周期 | 需求批准 → 候选人接受的自然日 | 按岗位族统计 |
| 试用期通过率 | 转正人数 ÷ 到期人数 | 招聘质量滞后指标 |
| 90 天留存率 | 入职 90 天仍在岗 ÷ 入职人数 | |

## 组织与人才指标

| 指标 | 口径 |
|---|---|
| 主动流失率（年化） | 主动离职人数 ÷ 平均在职人数 × 12 ÷ 统计月数 |
| 内部晋升占比 | 内部晋升填补岗位数 ÷ 岗位填补总数 |
| 关键岗位继任覆盖率 | 有 ready-now 继任者的关键岗 ÷ 关键岗总数 |
| IDP 完成率 | 按期完成的 IDP 行动数 ÷ 到期行动数 |

## 流程术语

| 术语 | 定义 |
|---|---|
| HC | Headcount，核定编制 |
| 成功画像 | 12 个月后该岗位做得好的具体描述（用人标准核心） |
| 结构化面试 | 同岗同维度同权重同评分锚点的面试 |
| STAR | 情境 Situation / 任务 Task / 行动 Action / 结果 Result |
| SBI 反馈 | 情境-行为-影响的反馈结构 |
| 校准会 | 跨团队对齐评定尺度的会议（calibration） |
| 九宫格 | 绩效 × 潜力的人才盘点矩阵 |
| IDP | Individual Development Plan，个人发展计划 |
| PIP | Performance Improvement Plan，绩效改进计划 |
| ready-now / ready-later | 继任者可立即接任 / 需 1-2 年培养 |

## 状态用词

招聘：`需求中 / JD 上架 / 筛选中 / 面试中 / Offer 中 / 已接受 / 已入职 / 暂停 / 关闭`
绩效：`目标设定 / 期中回顾 / 评定中 / 校准中 / 反馈中 / 已完成`
培养：`规划中 / 进行中 / 已达标 / 已暂停`
