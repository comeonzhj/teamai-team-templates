# 决策记录（Decision Log）

> 标准口径、流程、政策类决策都要留痕；**旧记录不改写**，推翻则新增并注明「取代 D-xxx」。

## 模板

```markdown
## D-NNN｜一句话决策标题
- 日期：YYYY-MM-DD
- 状态：提议 | 已通过 | 已取代 | 已废弃
- 决策人：@who（参与：@a；会签：法务/财务）
- 背景：
- 备选方案：A…（选了）/ B…（放弃，为什么）
- 影响：对流程、标准、口径、排期的约束；过渡安排
- 取代：无 / D-xxx
```
