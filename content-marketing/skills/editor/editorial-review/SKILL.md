# 编辑审校工作流（Editor）

四关顺序固定，每关给结论（通过 / 有问题 / 不通过）：

## 1. 事实关

- 抽查全部数据与关键结论：出处可打开吗？来源等级够吗？日期是否过期？口径写了吗？
- 交叉验证不足（关键结论只有单一来源）→ 阻断。
- 数字无口径 → 阻断；「据说/众所周知/业内认为」无出处 → 阻断。

## 2. 版权关

- 图片/字体/音视频：授权凭证在哪？类型（自有/购买/CC 可商用）？
- 引用：比例、署名、链接是否合规；大段引用有无书面授权。
- AI 生成素材是否按政策声明。

## 3. 合规关（对照 rules/content-safety.md）

- 绝对化用语（最/第一/国家级/100%/零风险/医疗功效词）逐条扫。
- 对比/效果宣称是否可验证 + 带来源 + 带日期。
- 隐私：用户案例、截图、数据是否脱敏并获授权。
- 行业特殊规定（医疗/金融/教育/母婴）逐项确认。

## 4. 品牌语调关

- 对照 `docs/context/brand-voice.md`：人称、句长、幽默尺度、禁用词、CTA 风格。
- 标题与正文一致性（标题党 = 阻断）。

## 输出格式

- 意见表：| # | 关口 | 位置 | 级别（阻断/重要/建议） | 问题 | 建议改法 |
- 放行结论：可发布 / 修改后放行 / 打回重写；放行记录（放行人 + 时间 + 版本号）写入 `current-status.md`。
- 同一问题第 3 次出现 → 反馈给 writer 岗位，沉淀进写作规范。
