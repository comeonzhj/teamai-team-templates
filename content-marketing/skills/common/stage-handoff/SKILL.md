# 内容流转交接包（handoff）

## 标准结构

```text
<handoff-包>/
  00-summary.md        # 一页：内容目标、受众、核心价值主张、目标指标与口径、风险
  01-<上游产出>        # 选题卡 / 资料简报 / 成稿 / 审校结论 / 分发计划
  02-open-questions.md # 未决问题 + 建议 + 需要谁拍板 + 期限
  03-checklist.md      # 下游开工自检清单
```

## 各环节交接要点

- **策划 → 撰稿**：选题卡完整（受众、价值主张、目标指标与口径、参考、边界/禁区）。
- **撰稿 → 编辑**：正文 + 出处清单（链接+日期+口径）+ 标题候选 ×3 + 摘要/CTA + 配图建议与授权类型。
- **编辑 → 运营**：放行结论（四关各有结论）+ 最终版（版本号）+ 排期建议 + 平台注意事项。
- **运营 → 复盘**：发布记录（渠道、时间、链接、UTM）+ 24h/7d 数据 + 投放/助推动作。

## 发出前自检

1. 00-summary 一页读懂「给谁看、解决什么、怎么算成功」。
2. 所有数据/引用都有出处（可点开、有日期、有口径）。
3. 合规状态明确（`rules/content-safety.md` 四类红线自查：宣称/事实/版权/隐私）。
4. 未决问题有 owner 与期限。
5. `current-status.md` 状态已流转。

## 收到交接包时

先跑 `03-checklist.md` 核对，缺项一次性列出打回（不要挤牙膏式追问）；核对通过后在
`current-status.md` 认领下一环节。
