# 单人内容全流程（solo-content-run）

Agent 放大了每个人的产能：策划能写稿、运营能做图、产品能写文案。**产出能不能进协作，
取决于是否满足内容产出契约**（`rules/content-output-contract.md`）与内容安全红线
（`rules/content-safety.md`）。

## 1. 起点：选题卡先行（10 分钟）

- 用 `skills/strategy/topic-research` 的方法快速定：给谁看（受众画像）、解决什么、
  为什么现在、目标指标（带口径）。
- 热点先过四问（相关性/独特角度/时间窗/合规风险）；高合规风险先标「待合规确认」。

## 2. 资料：来源分级 + 交叉验证

- 按 `skills/writer/content-writing` 的资料方法：一手 > 权威 > 行业媒体 > 自媒体；
  关键结论 ≥ 2 个独立来源；出处（链接 + 日期 + 口径）随稿流转；反证找一条。

## 3. 成稿：结构先行

- 提纲（标题候选 ×3、导语钩子、分节要点、证据落点、CTA）→ 正文（倒金字塔、短段、
  小标题覆盖读者会搜的问题）→ 语调对照 `docs/context/brand-voice.md`。

## 4. 自检四关（契约第 2 条，逐个跑）

| 关口 | 调用 | 通过标准 |
|---|---|---|
| 事实 | `fact-checker` | 无「无出处/夸大」条目，或已弱化改写 |
| 语调 | `brand-voice-keeper` | 必改项清零 |
| 合规 | 对照 `rules/content-safety.md` + `guard-claims` | 无红线命中 |
| 可读/搜索 | `seo-reviewer` | 重要建议已处理 |

## 5. 进协作（免返工清单，契约第 4 条）

1. 交付包完整（正文 + 出处清单 + 标题候选 + 摘要/CTA + 配图建议 + AI 参与说明）
2. 自检通过，阻断项清零
3. 与目标指标对齐（指标 + 口径）
4. `current-status.md` 登记（状态 + 负责人 + 排期）

然后交编辑岗走正式放行（四关审校 + 放行记录）；**自检做得好，一次过**。

## 6. 收尾

- 更新 `current-status.md`（发布后 24h/7d 回填数据）；新口径/新决策写 `decisions.md`。
- 爆款/翻车经验 `teamai contribute` 沉淀。

## 边界

- 涉及重大宣称、法律/医疗/金融内容、对外公告：不单人直发，先走编辑与合规正式审核。
- 不确定合规状态时宁可停：标「待合规确认」，不赌。
