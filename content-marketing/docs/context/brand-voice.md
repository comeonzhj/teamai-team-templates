## 1. 品牌人格（3 个关键词 + 1 个反面）

> 【示例｜替换为你们的】专业但不端着 · 有观点不迎合 · 实用到能立刻动手；反面：故作高深的术语堆砌。

## 2. 语言规则

| 维度 | 规范 | 示例 |
|---|---|---|
| 人称 | 对读者称「你」，自称「我们」 | ✅「你可以先做 X」 ❌「用户应当做 X」 |
| 句长 | 平均 ≤ 25 字，长句拆短 | |
| 术语 | 首次出现一句话解释，口径见 `glossary.md` | |
| 幽默 | 可以自嘲，不调侃读者与第三方 | |
| 标点 | 中文全角；数字与单位半角 | 「3 天」「10%」 |

## 3. 禁用与慎用

- 禁用词：【按公司政策填：极限词、夸大词、内部黑话、夸大承诺】
- 慎用：感叹号（每篇 ≤ 2 个）、网络热梗（生命周期 < 3 个月的不用）
- 合规禁用：见 `rules/content-safety.md`（广告法绝对化用语、医疗功效、保本保收益）

## 4. 结构风格

- 标题：信息前置，不玩双关牺牲清晰；15-30 字。
- 导语：前 100 字说清「这篇解决什么问题」。
- 正文：小标题 + 短段（≤ 4 行）+ 列表/步骤 + 例子。
- 结尾：给一个明确 CTA（且只有一个）。

## 5. 渠道差异

| 渠道 | 语气 | 长度 | 特殊要求 |
|---|---|---|---|
| 公众号/博客 | 深度、结构化 | 1500-3000 字 | 小标题覆盖搜索问题 |
| 小红书/社区 | 轻快、口语 | 500-800 字 | 首图 + 标签规范 |
| 短视频/直播 | 节奏快、口语 | 按脚本 | 前 3 秒钩子 |
| Newsletter | 一对一感 | 800-1200 字 | 有固定栏目 |

## 6. 标题与 CTA 规范

- 标题候选 ×3：一个信息型、一个悬念型、一个数字型。
- 禁止标题党：标题承诺什么，正文必须兑现（不兑现 = 审校阻断项）。
