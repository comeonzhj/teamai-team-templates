# 指标口径与术语表（Glossary）

> 数字口径的唯一定义处。汇报、复盘、选题打分均以本表为准；口径变更走 `decisions.md`。

## 内容指标

| 指标 | 口径 | 备注 |
|---|---|---|
| 曝光（Impression） | 内容在用户屏幕上实际展示的次数 | 各平台定义略有差异，跨平台汇总注明来源 |
| 点击率（CTR） | 点击数 ÷ 曝光数 | 标题/封面效果 |
| 阅读完成率 | 读到文末 ≥ 80% 的读者占比（口径见 D-007） | 长文质量核心指标 |
| 互动率 | （赞+评+转+藏）÷ 阅读数 | |
| 线索转化 | 表单提交/留资数，归因窗口 7 天，UTM 识别渠道 | 与销售口径对齐 |
| 品牌词搜索量 | 品牌关键词在目标市场的搜索指数 | 季度看趋势 |

## 内容生产术语

| 术语 | 定义 |
|---|---|
| 支柱（Pillar） | 内容策略中的主题类别（方法论/案例/观点/产品） |
| 常青选题 | 不受时效限制、可长期带来搜索流量的选题 |
| 热点窗口 | 热点具备内容价值的时间段（过窗不追） |
| 完稿 | 通过四关审校、放行待发布的版本（有版本号） |
| 四关审校 | 事实关 / 版权关 / 合规关 / 品牌语调关 |
| 放行 | 审校给出「可发布」结论并留记录（放行人 + 时间 + 版本号） |
| 内容审计 | 栏目级复盘：淘汰低效方向、标注高价值常青选题 |
| 反证检查 | 资料搜集时主动找一条反对/负面证据 |

## 流程状态

`选题中 → 资料收集中 → 写作中 → 审校中 → 待发布 → 已发布 → 复盘中 → 已归档`
（允许「带风险进入」下一状态，必须在 `current-status.md` 标注。）
