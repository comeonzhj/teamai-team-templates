# 决策记录（Decision Log）

> 约束后续工作的选择都要留痕；**旧记录不改写**，推翻则新增并注明「取代 D-xxx」。编号递增。

## 模板

```markdown
## D-NNN｜一句话决策标题
- 日期：YYYY-MM-DD
- 状态：提议 | 已通过 | 已取代 | 已废弃
- 决策人：@who（参与：@a @b）
- 背景：为什么要定这件事
- 备选方案：A…（选了）/ B…（放弃，为什么）
- 影响：对排期、栏目、渠道、口径的约束
- 取代：无 / D-xxx
```

## D-008｜新增「数据报告」栏目，月更
- 日期：`YYYY-MM-DD`
- 状态：已通过
- 决策人：@content-lead（参与：@strategy-a @ops-a）
- 背景：案例类内容的说服力依赖可引用的数据；受众调研中 62% 的读者会搜索行业数据。
- 备选方案：A. 独立栏目月更（选了：可累积为年度报告资产）；B. 数据散落在案例中（放弃：无法被检索与引用）。
- 影响：每月 1 篇产能占用；「内容策略」支柱占比调整（案例 30% → 25%，方法论 40% 不变）；数据口径统一引用 glossary.md。
- 取代：无

## D-007｜公众号阅读完成率口径改为「读到文末 ≥ 80% 的读者占比」
- 日期：`YYYY-MM-DD`
- 状态：已通过
- 决策人：@ops-a
- 背景：旧口径「平均阅读时长 / 预估时长」在长文中失真，无法横向比较。
- 备选方案：A. 新口径（选了：与平台后台一致、可复算）；B. 保留旧口径（放弃）。
- 影响：历史数据需按新口径回算 3 个月；所有复盘报告统一使用新口径。
