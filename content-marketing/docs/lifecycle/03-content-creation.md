# 环节 3 · 内容创作（Creation）

> 主责：writer ｜ 产出 → 环节 4 审校

## 目标

产出**结构清晰、可读、语调合规、证据落位**的成稿。

## 进入条件

- 资料简报完成（环节 2 DoD）；选题卡的目标指标明确。

## 关键动作

1. **提纲先行**（`../templates/content-outline.md`）：标题候选 ×3、导语钩子、分节要点、
   证据落点（哪条资料支撑哪节）、结论与 CTA。
2. **写正文**：倒金字塔、段落 ≤ 4 行、小标题覆盖读者会搜的问题、具体例子替代形容词。
3. **语调对齐**：`../context/brand-voice.md`（人称、句长、禁用词、渠道差异）。
4. **合规自查**：绝对化用语、宣称可溯源、隐私脱敏（`rules/content-safety.md`）。
5. **可读性与 SEO 自查**：删空词、首段点题、内链/外链合理。
6. **交付打包**（见 `stage-handoff`）：正文 + 出处清单 + 标题候选 ×3 + 摘要/CTA + 配图建议（授权类型）+ AI 参与说明。

## 产出物

- 成稿（带版本号）+ 出处清单 + 标题候选

## DoD

- [ ] 每节结论有证据落点，出处随稿流转
- [ ] 语调对照品牌规范自查过
- [ ] 合规自查过（四类红线）
- [ ] 标题候选 ×3，正文兑现标题承诺

## 交接

→ 审校（环节 4）：成稿 + 出处清单 + AI 参与说明
→ 运营（环节 5 并行）：排期预沟通、配图需求

## 常见坑

- 先写后找资料 → 结论没证据，返工。
- 标题党：标题承诺、正文不兑现（审校必判阻断）。
- 全篇一个 CTA 都没有，或塞三个 CTA。
