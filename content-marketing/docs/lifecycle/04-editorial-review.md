# 环节 4 · 编辑审校与合规（Editorial Review）

> 主责：editor ｜ 产出 → 环节 5 发布

## 目标

四关全过，给出可执行的放行结论——**合规是人的责任，不是 hook 的责任**。

## 进入条件

- 成稿（带版本号）+ 出处清单 + AI 参与说明齐全。缺件退回，不排队等补。

## 关键动作（顺序固定）

1. **事实关**：抽查全部数据与关键结论（来源等级、日期、口径、链接有效性）；
   关键结论单一来源 → 阻断。
2. **版权关**：素材授权凭证、引用比例与署名、AI 生成声明。
3. **合规关**：绝对化用语、宣称可验证性、隐私脱敏、行业特殊规定。
4. **品牌语调关**：对照 `../context/brand-voice.md`；标题与正文一致性（标题党 = 阻断）。
5. **意见分级**：`阻断 / 重要 / 建议`，每条给「位置 + 问题 + 建议改法」。
6. **放行决策**：可发布 / 修改后放行 / 打回重写；留放行记录（放行人 + 时间 + 版本号）。

## 产出物

- 审校清单（`../templates/review-checklist.md`）+ 放行结论

## DoD

- [ ] 四关各有明确结论
- [ ] 阻断项清零，重要项有结论
- [ ] 放行记录写入 `../context/current-status.md`
- [ ] 同一问题第 3 次出现已反馈写作规范

## 交接

→ 运营（环节 5）：放行版（版本号）+ 平台注意事项 + 排期建议

## 常见坑

- 只改错别字不看事实与合规——审校的价值在前两关。
- 意见写「这里不太行」，没有改法。
- 带阻断项排期发布（协作公约禁止）。
