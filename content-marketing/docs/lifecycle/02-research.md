# 环节 2 · 资料搜集与事实核查（Research）

> 主责：writer ｜ 产出 → 环节 3 创作

## 目标

拿到**可引用、可溯源、带口径**的证据，让成稿经得起事实关审校。

## 进入条件

- 选题卡完整（受众、价值主张、目标指标、边界/禁区）。

## 关键动作

1. **列问题清单**：读者会搜的问题 + 我们要回答的问题 + 需要数据支撑的结论。
2. **来源分级检索**：一手官方/原始报告 > 权威机构 > 行业媒体 > 自媒体（后两类只做线索）。
3. **交叉验证**：关键结论 ≥ 2 个独立来源；冲突数据择权威并注明差异。
4. **反证检查**：主动找一条反对/负面证据，写进简报（防幸存者偏差）。
5. **记录出处**：每条结论 = 来源 + 链接 + 发布/访问日期 + 数据口径 + 来源等级。
6. **素材合规预检**：图片/字体/音视频授权类型先确认（`rules/content-safety.md`）。

## 产出物

- 资料简报（`../templates/research-brief.md`）：结论清单 + 出处 + 冲突与存疑 + 反证 + 素材授权

## DoD

- [ ] 关键结论均有 ≥ 2 个独立来源（或明确标注单源存疑）
- [ ] 每条数据带口径、日期、链接
- [ ] 反证已记录
- [ ] 无法证实的内容已删除或改写为「据称 + 来源性质」

## 交接

→ 创作（环节 3）：资料简报 + 出处清单（随稿一直流转到审校）

## 常见坑

- 只搜支持自己观点的证据。
- 用自媒体转述当一手数据。
- 引用过期数据不标注日期（行业数据 12 个月即需复核）。
