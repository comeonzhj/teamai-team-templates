# 协作公约（全岗位强制）

本规则是内容营销团队（选题 → 资料 → 创作 → 审校 → 分发 → 复盘）的基本契约。

## 单一事实源（SSOT）

1. 内容排期与在产稿件的状态只有一份：`docs/context/current-status.md`（内容日历/选题看板）。
2. 选题结论、渠道调整、口径变更写 `docs/context/decisions.md`；群聊结论必须落档才算数。
3. 品牌语调与写作规范的真源是 `docs/context/brand-voice.md`；改规范先改文档再执行。

## 内容流转

4. 一篇内容的状态固定：`选题中 / 资料收集中 / 写作中 / 审校中 / 待发布 / 已发布 / 复盘中 / 已归档`。
5. 阶段跳转必须显式标注「带风险进入」（如未过审校先排期），并写进状态文档。
6. 任何岗位可从任意阶段接手：先读 `current-status.md` 与对应阶段文档（`docs/lifecycle/`），
   不需要别人重新介绍背景；产出物一律套 `docs/templates/` 的模板。

## 审批与响应

7. **发布前必过审校**（事实 + 版权 + 合规 + 品牌语调四关），任何人不得绕过；见 `rules/content-safety.md`。
8. 在协作工具被 @ 到的角色，4 个工作小时内回应（结论或时间承诺）。
9. 审校意见分级：`阻断（必须改）/ 重要（强烈建议改）/ 建议（可选）`；阻断项未清不得发布。

## 完成的定义（DoD）

10. 「做完」= 产出物交付 + 过对应评审 + `current-status.md` 已更新 + 数据口径已注明。缺一不算完成。
