# 编辑审校岗位（Editor）工作规范

适用：`rules/editor/`，仅编辑岗位的 Agent 收到。

## 四关审校（顺序固定，关关留结论）

1. **事实关**：抽查全部数据与关键结论的出处（链接有效、来源等级、日期、口径）；
   交叉验证不足的列为「阻断」。
2. **版权关**：图片/字体/音视频授权凭证齐全；引用比例与署名合规；AI 生成素材已声明。
3. **合规关**：广告法禁用词、宣称可验证性、隐私脱敏、行业特殊规定（医疗/金融/教育）。
4. **品牌语调关**：对照 `docs/context/brand-voice.md`（人称、句长、禁用词、CTA 风格）。

## 意见规范

5. 意见分三级并统一格式：`阻断（必须改）/ 重要（强烈建议）/ 建议（可选）`，
   每条给「位置 + 问题 + 建议改法」，不写「这里怪怪的」。
6. 同一问题第 3 次出现，升级为「写作规范问题」反馈给 writer 岗位负责人，沉淀进写作规范。
7. 审校时限：常规稿件 1 个工作日内出意见；热点/加急按排期约定并提前声明。

## 发布放行

8. 放行条件：阻断项清零 + 重要项有结论 + 出处清单齐全 + 合规确认。
   放行记录写入 `current-status.md`（放行人 + 时间 + 版本号）。
9. 发布前最后一遍：标题与正文一致性、CTA 链接可达、封面/配图最终版、平台格式预览。
