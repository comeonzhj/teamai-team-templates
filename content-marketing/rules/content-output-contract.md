# 内容产出契约（Content Output Contract）—— 任何岗位产出对外内容的准入基线

**适用范围：全团队（准线）。** 策划、撰稿、编辑、运营之外，任何岗位用 Agent 直接产出
对外内容（文案、海报文字、短视频脚本、社群话术、产品内文案）都适用。
目标：**产出可直接进排期、过审、发布，不需要返工重写**。

> 红线部分见 `rules/content-safety.md`（强制）；本契约是「能不能直接进协作」的门槛。

## 1. 交付包完整（缺一不进排期）

- 正文（带版本号）+ 出处清单（链接 + 日期 + 口径）+ 标题候选 ×3 + 摘要/CTA +
  配图建议（含授权类型）+ AI 参与说明。
- 用 `docs/templates/` 对应模板的结构，不自创格式。

## 2. 四关自检（发布前由产出方先跑一遍）

| 关口 | 自检 | 调用 |
|---|---|---|
| 事实 | 数据/结论有出处、口径、日期；单一来源已标注 | `fact-checker` |
| 版权 | 素材授权明确、引用署名、AI 生成已声明 | 对照 rules/content-safety.md |
| 合规 | 无绝对化用语、宣称可验证、隐私脱敏 | `guard-claims` hook + 对照红线 |
| 语调 | 人称/句长/禁用词/渠道风格符合品牌语调 | `brand-voice-keeper` |

编辑岗的正式放行流程不变（四关审校 + 放行记录）；自检的作用是让你的产出**一次过**。

## 3. 数字与口径

- 数字带口径、来源、截止时间；口径以 `docs/context/glossary.md` 为准，不得另造。
- 不确定的标注「待核实」，不硬写。

## 4. 免返工清单（进排期前）

1. [ ] 交付包完整（第 1 条各项）
2. [ ] 四关自检通过（阻断类问题清零）
3. [ ] 与选题卡/内容策略的目标指标对齐（写明指标与口径）
4. [ ] `current-status.md` 已登记（状态 + 负责人 + 排期）

## 5. 谁来把关

自检（产出方，含其 Agent）→ 编辑四关审校 → 放行记录 → 排期发布。
Agent 的结论是证据，放行是人的动作。
