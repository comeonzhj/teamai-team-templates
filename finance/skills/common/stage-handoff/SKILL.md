# 财务流程交接包（handoff）

## 标准结构

```text
<handoff-包>/
  00-summary.md        # 一页：事项、期间、口径、金额量级（汇总口径）、风险、需要谁审批
  01-<上游产出>        # 预算包 / 审核清单 / 关账说明 / 申报表 / 报告
  02-open-questions.md # 未决问题 + 建议 + 需要谁拍板 + 期限
  03-checklist.md      # 下游开工自检清单
```

## 各环节交接要点

- **FP&A → 各部门/核算**：批准版预算（版本号）+ 假设说明 + 费用标准 + 预算科目映射。
- **业务/费用 → 核算**：单据链（合同/发票/验收/审批）+ 归属期间 + 预算额度核对结果。
- **核算 → 税务**：账税差异台账 + 收入确认明细（按税种口径）+ 发票汇总。
- **核算 → FP&A**：关账说明（异常事项、手工调整清单、遗留问题）+ 科目余额表（口径注明）。
- **FP&A → 管理层**：经营报告 + 差异分析 + 行动项（owner/期限）。
- **全员 → 内控/审计**：证据包（凭证 → 单据 → 审批链）+ 口径说明 + 例外事项清单。

## 发出前自检

1. 数字三要素齐全（口径、来源、截止时间）；报表内部勾稽自检平衡。
2. 制单/复核人留名；证据可追溯到原始单据。
3. **无敏感泄露**：银行账号掩码、薪酬与单客户明细按汇总口径（`rules/financial-controls.md`）。
4. 未决问题有 owner 与期限；`current-status.md` 状态已流转。

## 收到交接包时

跑 `03-checklist.md` 核对（勾稽、口径、证据、审批四类），缺项一次性列清单打回。
