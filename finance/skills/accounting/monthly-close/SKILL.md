# 月结关账工作流（Accounting）

## 0. 关账前（T-3 ~ T-1）

- 通知节点与冻结规则（close freeze：不改科目/口径/流程）。
- 收齐单据：费用、发票、银行回单、资产/存货变动；缺单清单发业务方（T-2 前补齐）。

## 1. 关账主清单（照 `docs/templates/close-checklist.md`）

1. **截止性测试（cut-off）**：收入/成本/费用的期间归属，跨期单据逐笔检查。
2. **计提与摊销**：薪酬、租金、折旧、摊销、预提费用；计算表可复算。
3. **往来核对**：应收/应付/其他往来与客户供应商对账，账龄与坏账准备。
4. **存货与资产**：盘点差异、跌价/减值迹象、资本化与费用化判断。
5. **汇兑损益**：外币余额重估，汇率来源与政策一致（`accounting-standards.md`）。
6. **结转与试算平衡**：损益结转、成本结转、科目余额表借贷平衡。

## 2. 四类对账（先对账后出数）

总账 ↔ 明细账；账 ↔ 银行；账 ↔ 税（含账税差异台账）；账 ↔ 业务系统（订单/库存/薪酬）。
差异三选一：查明更正 / 挂账待查（owner + 期限）/ 重要性豁免（写依据）——禁止沉默抹平。

## 3. 复核与关账说明

- 制单/复核分离；复核看勾稽、证据、口径。
- 关账说明：本期异常、手工调整逐笔原因、遗留问题与 owner、与上期口径差异。

## 4. 输出

科目余额表（口径注明）+ 关账说明 + 账税差异台账 → 交税务与 FP&A（见 `stage-handoff`）。
