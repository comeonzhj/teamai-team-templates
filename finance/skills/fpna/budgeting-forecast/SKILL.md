# 预算与预测工作流（FP&A）

## 1. 预算编制（假设驱动）

照 `docs/templates/budget-template.md`：

- **从业务假设出发**：收入 = 量 × 价（分产品/渠道）；成本 = 量 × 单位成本 + 固定；
  费用 = 人数 × 人效 + 费用率；资本开支按项目。每项假设写依据（历史/合同/市场）。
- 自上而下（目标）与自下而上（部门申报）**双向对齐**，差异在评审会上收敛。
- 版本管理：v1 编制 / v2 评审 / v3 批准下达；下达后变更走预算调整（`decisions.md`）。
- 敏感性分析：关键假设 ±10% 对利润/现金流的影响（至少 3 个情景）。

## 2. 滚动预测

- 月度/季度滚动：只调「已知变化 + 假设变化」，逐项说明差异原因，不做无解释平移。
- 13 周现金流预测与年度预算口径对齐（与 treasury 协同）。

## 3. 差异分析（照 `docs/templates/variance-analysis.md`）

- 三比：实际 vs 预算、实际 vs 同期、实际 vs 上期。
- **量价拆解**：价格 × 数量 × 结构 × 汇率；一次性因素单列剔除后看经营性差异。
- 阈值（±5% 或 ±10 万）以上必解释；解释要有业务事实支撑，不知道就写「待业务确认 + owner」。

## 4. 经营报告（照 `docs/templates/management-report.md`）

结论先行 → 指标（口径 + 三比）→ 驱动因素 → 风险与建议 → 行动项。
数字纪律照 `rules/accuracy-discipline.md`（口径/来源/截止时间），发布前勾稽自检。
