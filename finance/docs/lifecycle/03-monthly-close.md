# 环节 3 · 核算与月结（Monthly Close）

> 主责：accounting ｜ 产出 → 环节 4 税务、环节 5 分析

## 目标

按 `close-calendar.md` 的节点准时、准确、可审计地出数。

## 进入条件

- 单据收齐（D-2 缺单清单清零或有处置结论）；冻结期规则生效。

## 关键动作

1. **cut-off 测试**：收入/成本/费用期间归属，跨期单据逐笔检查。
2. **计提与摊销**：薪酬、租金、折旧、摊销、预提；计算表可复算。
3. **四类对账**：总账↔明细、账↔银行、账↔税、账↔业务系统；差异逐项解释
   （查明更正 / 挂账待查 / 重要性豁免——见 `rules/accuracy-discipline.md`）。
4. **存货与资产、汇兑损益、结转、试算平衡**（照 `../templates/close-checklist.md`）。
5. **复核**：制单/复核分离；勾稽、证据、口径三看。
6. **关账说明**：异常事项、手工调整逐笔原因、遗留问题与 owner、口径变化提示。

## 产出物

- 科目余额表（口径注明）、关账说明、账税差异台账、对账表

## DoD

- [ ] 试算平衡、报表勾稽自检通过
- [ ] 四类对账差异全部有处置结论
- [ ] 手工调整逐笔列示并复核
- [ ] 关账说明完成，`current-status.md` 更新

## 交接

→ 税务（环节 4）：账税差异台账 + 按税种口径的收入/成本明细
→ 分析（环节 5）：科目余额表 + 关账说明

## 常见坑

- 差异用「尾差调整」抹平（审计红旗）。
- 手工分录只给合计数，无法追溯。
- 关账拖节点，导致申报与报告连锁延迟。
