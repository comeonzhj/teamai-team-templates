# 环节 5 · 分析与经营报告（Reporting & Analysis）

> 主责：fpna ｜ 输入：环节 3 的账、环节 1 的预算 ｜ 产出：管理决策依据

## 目标

把账变成**能做决策的信息**：结论先行、差异可解释、建议可执行。

## 进入条件

- 关账完成（科目余额表 + 关账说明）；预算基期明确（版本号）。

## 关键动作

1. **差异分析**（照 `../templates/variance-analysis.md`）：实际 vs 预算/同期/上期三比；
   量价拆解（价格 × 数量 × 结构 × 汇率）；一次性因素单列；阈值以上（±5% 或 ±10 万）必解释。
2. **经营报告**（照 `../templates/management-report.md`）：结论先行（≤ 3 条）→ 指标（口径 + 三比）
   → 驱动因素 → 风险与建议 → 行动项（owner/期限）。
3. **专题分析**：按管理层关注点（毛利下滑、费用超支、现金流缺口）做专题，一页纸给结论。
4. **数字纪律**（`rules/accuracy-discipline.md`）：口径/来源/截止时间三要素；发布前勾稽自检。
5. **保密**（`rules/financial-controls.md`）：对外/对上材料按需知脱敏。

## 产出物

- 经营报告 + 差异分析 + 专题分析 + 行动项清单

## DoD

- [ ] 结论有数据支撑，差异解释到业务事实
- [ ] 每个数字三要素齐全
- [ ] 报表勾稽自检通过
- [ ] 行动项有 owner 与期限，并已进 `current-status.md`

## 交接

→ 管理层：报告 + 建议
→ 各部门：责任中心差异与改进项
→ 预算（环节 1）：差异结论修正预测假设

## 常见坑

- 报告罗列数字没有结论（「收入 1.2 亿」不是结论）。
- 差异解释写「市场原因」这类无证据的筐。
- 报告数字与账不一致（发布前勾稽自检是硬要求）。
