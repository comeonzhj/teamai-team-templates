# 环节 2 · 交易与费用审核（Transaction & Expense Audit）

> 主责：accounting ｜ 产出 → 环节 3 月结

## 目标

在入账前把住**真实性、合规性、完整性、权限**四关，减少月结调整与审计问题。

## 进入条件

- 费用标准与审批权限（`../context/finance-policy.md`）、预算额度可用。

## 关键动作

1. **费用四关**（照 `../templates/expense-audit-checklist.md`）：
   - 真实性：单据链（合同/发票/验收/审批）完整、业务真实
   - 合规性：符合标准（超标有事前审批）、发票合规（抬头税号、真伪查验）
   - 完整性：期间归属（cut-off）、金额一致、附件齐
   - 权限：审批人与金额分级匹配（`finance-policy.md`）
2. **应收应付**：发票与合同/订单匹配、账龄跟踪、到期提醒、异常（争议/坏账迹象）即时上报。
3. **异常处理三选一**：退回补正 / 挂账待查（owner + 期限）/ 特批（留审批记录）。
4. **分录**：按 `../templates/journal-voucher.md` 制单，摘要写业务事实，制单复核分离。

## 产出物

- 审核结论（通过/退回/挂账）、会计分录、异常事项清单

## DoD

- [ ] 四关逐项有结论
- [ ] 分录可追溯到原始单据
- [ ] 异常事项有 owner 与期限
- [ ] 无「先入账后补单」

## 交接

→ 月结（环节 3）：入账数据 + 异常清单 + 挂账待查项

## 常见坑

- 发票合规但业务不真实（虚开风险）——只看票面不看业务。
- 跨期费用乱挂，月结 cut-off 被动。
- 审批人与权限表不符（越权审批无效）。
