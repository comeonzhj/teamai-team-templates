# 决策记录（Decision Log）

> **会计政策与口径变更是重大事项**，必须留痕：依据、影响、过渡安排。
> 旧记录不改写；推翻则新增并注明「取代 D-xxx」。

## 模板

```markdown
## D-NNN｜一句话决策标题
- 日期：YYYY-MM-DD
- 状态：提议 | 已通过 | 已取代 | 已废弃
- 决策人：@who（参与/会签：@a；外审/税务顾问意见：）
- 背景：为什么现在要定
- 备选方案：A…（选了）/ B…（放弃，为什么）
- 依据：准则/政策文号/合同条款
- 影响：对报表、口径、系统、流程的影响（含金额量级）；过渡安排
- 取代：无 / D-xxx
```
