# 指标口径与术语表（Glossary）

> 数字口径的唯一定义处（与 `accounting-standards.md` 一致）；汇报与分析以本表为准。
> 口径变更走 `decisions.md`。

## 报表指标

| 指标 | 口径 | 备注 |
|---|---|---|
| 营业收入 | 合并抵消后、不含税、按收入确认政策 | 与合同额/开票额区分 |
| 毛利率 | （收入 − 营业成本）÷ 收入 | 分产品口径注明 |
| 费用率 | 期间费用 ÷ 收入 | 三费分开看 |
| EBITDA | 净利润 + 所得税 + 利息 + 折旧摊销 | 调整项逐项列示 |
| 经营性现金流 | 现金流量表「经营活动产生的现金流量净额」 | 与净利润差异要能解释 |
| 资产负债率 | 总负债 ÷ 总资产 | 年末/期末口径注明 |

## 预算与分析

| 指标 | 口径 |
|---|---|
| 预算达成率 | 实际 ÷ 批准版预算（v3） |
| 差异率 | （实际 − 对比基期）÷ 对比基期；阈值 ±5% 或 ±10 万必解释 |
| 一次性因素 | 非经常性、不可持续的损益项（单列剔除后看经营性差异） |
| 滚动预测 | 按月/季更新的 12 个月展望，只调已知变化与假设变化 |

## 资金与税务

| 术语 | 定义 |
|---|---|
| 13 周现金流预测 | 按周滚动的 13 周现金收支预测（基准/紧缩/压力情景） |
| 账税差异 | 会计口径与税务口径的差异（永久性/暂时性） |
| 三流一致 | 合同、发票、资金流一致 |
| 重要性水平 | 【填：如税前利润的 5%】——低于此差异可豁免但须写依据 |
| 勾稽 | 报表/账表之间可互相验证的数学关系 |
| 关账冻结期 | D-2 ~ D+4：不改科目、口径、流程 |

## 状态用词

关账：`未开始 / 进行中 / 已完成 / 阻塞`
预算：`编制中 / 评审中 / 已批准 / 已下达 / 调整中`
申报：`待准备 / 申报中 / 已申报 / 已缴款 / 已归档`
审计：`资料提供中 / 现场审计 / 意见沟通 / 已出报告 / 整改中`
