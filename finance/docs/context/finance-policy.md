# 财务制度与审批权限（Finance Policy）

> 制度真源（负责人：finance-lead）。修订走 `decisions.md` 留痕并全员告知。

## 1. 费用与报销标准

| 类别 | 标准 | 单据要求 | 备注 |
|---|---|---|---|
| 差旅-交通 | 【填：按职级】 | 发票 + 行程单 | 经济舱/高铁二等座为默认 |
| 差旅-住宿 | 【填：城市分级】 | 发票 + 水单 | 超标需事前审批 |
| 业务招待 | 【填：人均上限】 | 发票 + 事由 + 参会名单 | 按次审批 |
| 办公采购 | 【填】 | 发票 + 验收 | 走采购流程 |

原则：先审批后支出；发票抬头税号合规；跨期费用按归属期间入账。

## 2. 审批权限（金额分级）

| 事项 | ≤ 1 万 | 1-10 万 | 10-50 万 | > 50 万 |
|---|---|---|---|---|
| 费用报销 | 部门负责人 | 部门负责人 + 财务 | + 分管副总 | + CEO |
| 采购/合同付款 | 部门负责人 + 财务 | + 分管副总 | + CEO | + 董事会（按章程） |
| 调整分录 | 会计主管 | 财务负责人 | 财务负责人 + CFO | CFO + CEO |

（阈值为示例，替换为你们的权限表；拆单规避审批视为违规，见 `rules/financial-controls.md`。）

## 3. 付款与收款

- 付款：制单 + 授权双人复核；大额按上表审批；紧急付款事后 24 小时内补审批。
- 收款账户变更必须**回拨核实**（防诈骗）；银行余额每日核对。

## 4. 预算管理

- 预算批准下达后，超预算支出走预算调整流程（说明原因 + 资金来源 + 影响）。
- 预算内支出仍走审批；预算不豁免审批。

## 5. 资料与数据

- 财务数据按「需知」传播；对外披露需 CFO/CEO 审批（`rules/financial-controls.md`）。
- 原始凭证保存期限：【填：按法定与公司制度孰长】。
