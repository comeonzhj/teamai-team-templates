# 上下文维护规则（强制，Agent 必读）

## 什么时候更新 `docs/context/current-status.md`

- 关账步骤完成/受阻（各科目关账状态）
- 预算/预测版本推进（编制中/评审中/已批准/已下达）
- 申报与支付节点状态变化
- 审计事项（外审/内审）进展
- 出现阻塞（系统、单据、跨部门配合）或解除

## 什么时候更新 `docs/context/decisions.md`

- **会计政策与口径变更**（收入确认、折旧、汇率、费用资本化等）——重大事项，必须写依据与影响
- 制度/审批权限调整、流程与系统变更
- 重要性水平、估计与假设的确定或修订
- 推翻旧决策：新增一条并标注「取代 D-xxx」，不改写历史

## 书写格式

- 状态短句 + 日期 + 负责人；数字带口径、来源、截止时间（`rules/accuracy-discipline.md`）。
- **绝不写入**：完整银行账号、身份证、薪酬明细、未公开财务数据（`rules/financial-controls.md`）；
  用掩码（****1234）与汇总口径。

## 边界

- 明细账、银行流水、申报表原件留在 ERP/银行/税务系统；docs/ 只放流程、口径、状态与聚合数字。
- 关账冻结期内不修改 accounting-standards.md 与口径类决策。
