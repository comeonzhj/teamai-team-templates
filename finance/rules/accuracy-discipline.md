# 数字准确性纪律（强制，不可删除）

财务数字的可信度是财务部门的产品。

## 1. 数字必带三要素

1. **口径**（怎么算的）、**来源**（哪个系统/哪张表）、**截止时间**（as of when）。
   例：「Q1 毛利率 42.3%，口径：合并抵消后，来源：ERP_URL 科目余额表，截止 2025-03-31。」
2. 口径以 `docs/context/glossary.md` 与 `accounting-standards.md` 为准；口径不同必须先归一再比较。

## 2. 对账与勾稽

3. **先对账，后出数**：总账与明细账、账与银行、账与税、账与业务系统（应收/应付/库存）四类勾稽
   每月必做；差异必须解释到科目级，不得「四舍五入抹平」。
4. 平衡检查：有借必有贷、报表勾稽（资产负债表未分配利润 ↔ 利润表净利润 + 期初）、
   现金流量表与货币资金余额核对。
5. 差异处理三选一，禁止沉默：查明更正 / 挂账待查（写明 owner 与期限）/ 重要性判断豁免（写明依据）。

## 3. 表达纪律

6. 单位统一（元/千元/万元，报表注明）；小数位统一（报表 2 位、比率 % 1 位）；
   负数表示法统一（括号或负号，全表一致）。
7. 禁止「大概」「约」出现在正式数字里；估算值必须标注「估算 + 方法 + 误差范围」。
8. 前期差错更正走 `decisions.md` 留痕，按政策处理（追溯/未来适用），不悄悄改历史数。

## 4. AI 产出的数字

9. Agent 生成的任何数字必须标注来源与口径；无法溯源的标注「待核对」，不得直接进报表。
10. 人必须复核后再用：制单 + 复核双人负责制照旧（见 `rules/financial-controls.md`）。
