# 内控与保密红线（强制，不可删除）

财务是公司资金与数据的守门人。违反本规则即风险事件。

## 1. 职责分离（Segregation of Duties）

1. 不相容职责不得由同一人兼任：**申请与审批**、**记账与付款**、**对账与记账**、**收款与记应收**。
   小团队无法完全分离时，必须有补偿性控制（第二人复核 + 月度抽查）并记录在案。
2. 复核留痕：凭证、报表、申报表必须有制单人与复核人；复核不是签字走过场，看勾稽与证据。

## 2. 审批权限

3. 支出/付款/调整分录按金额分级审批（权限表见 `docs/context/finance-policy.md`）；
   **超权限先补审批，再执行**；拆单规避审批视为违规。
4. 例外通道（紧急付款）必须事后 24 小时内补审批并说明原因。

## 3. 证据与审计线索

5. 每笔账都要能追溯：凭证 → 原始单据（合同/发票/验收/银行回单）→ 审批记录；
   证据按公司期限归档，缺失证据的分录不得入账。
6. 调整分录写明原因与依据，禁止「调平了事」；月末手工调整逐笔列示给复核人。

## 4. 数据保密

7. 财务数据（报表、现金流、成本、薪酬相关）按「需知」传播；**不进群聊、不进共享文档、
   不进 AI 提示词**。对外披露数据需 CFO/CEO 审批。
8. 银行与 ERP 凭据零落地：走 `env/secrets.yaml` + `teamai env exec --`；银行查询用只读账号，
   支付权限账号不接入任何自动化。`guard-pii` hook 会提示银行卡/身份证/薪酬命中。
9. 敏感输出脱敏：银行账号掩码（****1234）、供应商与客户金额按汇总口径。

## 5. Agent 附加约束

10. Agent 可做核对、勾稽、草拟、差异分析；**不做付款指令、不做税务申报提交、不改账**。
    任何金额与申报的最终结论由人确认（制单 + 复核）。
